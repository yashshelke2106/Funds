# DECISIONS

Every judgement call, the alternatives considered, and why. Newest at the bottom.

| ID | Date | Decision | Alternatives | Why |
|---|---|---|---|---|
| D-001 | 2026-09-25 | Source file layouts are taken from files actually downloaded on 2026-09-25 (AMFI `NAVAll.txt`, AMFI `DownloadNAVHistoryReport_Po.aspx?frmdt=02-Sep-2024`, mfapi `/mf/118825`). Parsers check the header line and stop with `FormatChangedError` if it differs. | Parse leniently by column position. | NAVAll now has **8 columns** (`Plan`, `Option` were added); the history report has a **different column order** from NAVAll. Parsing by position without checking would silently misread both. |
| D-002 | 2026-09-25 | The universe is **derived** from AMFI category headers (`Equity Scheme(s) - Large Cap Fund`), not a hand-typed list. Growth option only, with Direct/Regular pairs matched on (AMC, scheme name). | Hand-picked list of well-known funds. | A hand-picked list adds selection bias and can't be reproduced. AMFI spells the category two ways (`Equity Scheme` / `Equity Schemes`); both are normalised. |
| D-003 | 2026-09-25 | Holdings window = **Sep-2024 to Aug-2026** (24 complete months). | Rolling "last 24 months" from run date. | A fixed window makes results reproducible. Aug-2026 portfolios are due by 10-Sep-2026 (SEBI monthly disclosure deadline), so they are available. |
| D-004 | 2026-09-25 | NAV history is fetched from **Sep-2023** (12 months before the holdings window). | Fetch NAVs only for the holdings window. | Rolling 12-month tracking error then exists for every month of the holdings window, not just the last 12. Funds lacking this lookback are flagged (`covers_rolling_lookback`), not dropped. |
| D-005 | 2026-09-25 | **Eligibility** = Direct and Regular NAV history covers the whole holdings window **and** the AMFI ISIN matches the mfapi ISIN for both plans. Funds launched after the window start are excluded and listed. | Include young funds on a partial window. | Active share and TE averaged over different windows are not comparable. The exclusion is listed, not hidden. |
| D-006 | 2026-09-25 | NAV gaps are counted in **weekdays** (Mon–Fri). A gap of more than 5 is a *flag*, not a failure. Non-positive NAV and duplicate dates are *failures*. | Use the NSE holiday calendar. | No holiday calendar is in scope yet. Weekday counting over-flags around long holiday runs, so gaps are reviewed by hand rather than causing automatic failure. Revisit if flags turn out to be noisy. |
| D-007 | 2026-09-25 | Survivorship check compares Large Cap Growth scheme codes in the AMFI snapshot of **02-Sep-2024** against the current NAVAll. | Rely on AMC press releases. | This is mechanical and repeatable. The match is **by scheme code only**: the history report's `NAV Name` embeds plan and option text while NAVAll gives the bare name, so a name comparison would mark every scheme as renamed. Both names are output for a human to review. Limitation: a scheme launched *and* closed inside the window would be missed. |
| D-008 | 2026-09-25 | Unit-test fixtures are **verbatim excerpts** of the real files (rows copied, never edited). Only rule and metric unit tests (quality checks, P4 metrics) use small hand-built inputs; these exercise the logic, never feed an analysis, and live only under `tests/`. | Invented sample rows. | Complies with the no-synthetic-data rule. Some failure cases (e.g. a negative NAV) can't be taken from real data, and hand-calculated metric examples are required by the brief (P4). |
| D-009 | 2026-09-25 | **Look-ahead rule (applies from P2):** month M's portfolio counts as *known* only from the 11th day of month M+1 (SEBI 10-day disclosure deadline). Any analysis that pairs holdings with returns uses returns from after that date. | Treat month-end holdings as known at month end. | Using them at month end is look-ahead bias. |
| D-010 | 2026-09-25 | Candidate benchmark-weight proxies: Axis, Bandhan and HDFC Nifty 100 Index Funds (the only exact "Nifty 100 Index Fund" names in AMFI today). **Choice deferred to P2**: pick the one with the lowest tracking error to its own benchmark over the window. | Pick one now. | Choosing before seeing the data would be arbitrary. All three NAV series are fetched so the choice can be tested. |
